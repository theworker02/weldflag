# weldflag

Weld and reshape flag text streams with deterministic transforms.

**Site:** https://theworker02.github.io/weldflag/

## Install / run

```bash
git clone https://github.com/theworker02/weldflag.git
cd weldflag
node src/cli.js
node --test
```
